# Dr. Namita Mishra — Portfolio

🌐 **Live site:** [drnamita.github.io](https://drnamita.github.io)

A personal portfolio and professional site for Dr. Namita Mishra — physician, public health professional, and health data scientist. Built as a single-page site tracing a career arc from clinical medicine through public health to data science and teaching.

## About

Dr. Mishra brings 20+ years of clinical practice (emergency medicine, ENT, GI, general medicine) together with graduate training in public health and data science. This site covers:

- **About** — professional background and academic journey
- **Experience** — a timeline of roles from clinical residency through current research and teaching positions
- **Research** — ongoing projects in clinical research, public health, oncology, GIS, and data engineering
- **Teaching** — adjunct faculty roles and teaching philosophy
- **Credentials** — publications, posters, degrees, and certifications
- **Beyond the Clinic** — gardening, cooking, and sewing

## Built With

- Semantic HTML5 + CSS (no framework, single file)
- [Fraunces](https://fonts.google.com/specimen/Fraunces), [Inter](https://fonts.google.com/specimen/Inter), and [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts
- Vanilla JavaScript (scroll-based section tracking, mobile nav)
- Hosted free via [GitHub Pages](https://pages.github.com/)

## Updating the Site

1. Edit `index.html` directly in this repo (or replace it with an updated version).
2. Commit the change to the `main` branch.
3. GitHub Pages redeploys automatically — changes go live at [drnamita.github.io](https://drnamita.github.io) within a minute or two.
